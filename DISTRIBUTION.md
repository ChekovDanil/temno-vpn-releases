# Сборка и распространение TEMNO VPN

## Общая схема

1. Исходный код приложений хранится отдельно от бинарных релизов.
2. Каждая сборка получает версию, commit SHA, SHA-256 и журнал изменений.
3. Сначала версия публикуется как GitHub pre-release и проходит тестирование.
4. После подписи и проверки создаётся обычный GitHub Release.
5. `updates/latest.json` указывает на неизменяемые assets конкретного тега.
6. Сайт читает этот каталог и показывает только реально опубликованные платформы.
7. Клиенты проверяют каталог по HTTPS, SHA-256 и, до включения автоматической
   установки, отдельной Ed25519-подписью каталога.

GitHub хранит установочные файлы и историю версий. Amvera обслуживает сайт,
подписки и API, но не раздаёт тяжёлые установщики. Поэтому обновление сайта или
перезапуск Amvera не меняет ссылки на приложения.

## Windows

- Сборка: self-contained `win-x64`.
- Архитектура релиза: непривилегированный UI и отдельная подписанная Windows
  Service для TUN и сетевого ядра.
- Публикация: подписанный installer и portable ZIP в GitHub Releases.
- Обновление: приложение проверяет стабильный каталог, предлагает скачивание и
  устанавливает новую подписанную версию только после проверки подписи.
- До получения Authenticode-сертификата сборки остаются pre-release.

## Android

- Сборка: release AAB для магазина и подписанный APK для прямой установки.
- Подпись: постоянный production keystore хранится только в защищённых секретах
  CI; debug APK не публикуется как пользовательская версия.
- Публикация: AAB в магазине, APK и checksums в GitHub Releases.
- Обновление: магазин остаётся основным каналом; для прямого APK приложение
  показывает уведомление о новой версии из каталога.

## iOS и iPadOS

- Сборка выполняется на macOS через Xcode с Apple Team, App Group, Keychain
  Group и Network Extension capability.
- Тестирование идёт через TestFlight.
- Пользовательская версия распространяется через App Store.
- IPA в публичный GitHub Release не выкладывается. GitHub хранит номер версии,
  checksums воспроизводимых частей и журнал изменений, а каталог содержит ссылку
  на App Store.

## macOS

- Сборка: приложение и Packet Tunnel extension на macOS runner.
- Подпись: Developer ID; затем notarization и stapling.
- Публикация: подписанный DMG или PKG в GitHub Releases.
- Обновление: сначала безопасная ссылка на новый DMG; после стабилизации можно
  подключить подписанный Sparkle appcast или тот же Ed25519-каталог.

## Постоянные ссылки

- Страница всех версий: `https://github.com/ChekovDanil/temno-vpn-releases/releases`.
- Каталог обновлений: `https://raw.githubusercontent.com/ChekovDanil/temno-vpn-releases/main/updates/latest.json`.
- Сайт TEMNO получает ссылки из каталога и не зашивает номер версии в интерфейс.

Ссылки из `latest.json` всегда ведут на asset с конкретным тегом. Старые файлы
не заменяются, поэтому SHA-256 остаётся проверяемым и можно безопасно откатиться.
