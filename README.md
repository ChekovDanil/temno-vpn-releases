# TEMNO VPN Releases

Этот репозиторий предназначен только для официальных сборок TEMNO VPN и
не содержит ключи подписок, серверные конфигурации или пользовательские данные.

## Каналы

- `stable` — подписанные и проверенные пользовательские версии;
- `beta` — предварительные сборки для тестирования;
- `internal` — локальные debug-сборки, которые не публикуются в GitHub Releases.

Постоянная ссылка на последнюю стабильную сборку Windows будет иметь вид:

`https://github.com/ChekovDanil/temno-vpn-releases/releases/latest/download/TEMNO-VPN-Windows-x64.exe`

Android получает подписанный APK через GitHub Releases и AAB через магазин.
iOS распространяется через TestFlight и App Store; публичный IPA не публикуется.
macOS получает подписанный и нотарифицированный DMG через GitHub Releases.

Файл `updates/latest.json` используется сайтом и клиентами как каталог версий.
Автоматическое обновление включается только после добавления цифровой подписи
каталога и проверки подписи внутри приложений.
